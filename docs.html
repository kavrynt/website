Kavrynt documentation explains the product, architecture, and Kubernetes developer path for operating MCP servers across local, self-managed, and managed cloud clusters.

01

Architecture

AI client
  -> Kavrynt Gateway
  -> registered MCP server

kavryctl / Operator
  -> Kavrynt Registry
  -> Gateway route table
02

MVP lifecycle

define MCPServer
  -> sync to Registry
  -> Gateway loads route
  -> client calls /mcp/<name>
  -> upstream MCP server responds
03

Security baseline

The MVP uses non-root containers, read-only root filesystems, least-privilege RBAC, Helm validation, Docker builds, Go tests, vet, and vulnerability scanning in CI.

04

Trial access

Kavrynt source is private. Developer evaluation uses approved alpha or beta images that can be pulled directly into Kubernetes clusters.

Run trial images
05

License

Kavrynt is a private commercial SaaS product. Trial images are for approved evaluation and are not an open-source distribution.
