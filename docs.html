Kavrynt documentation explains the product, architecture, and local developer path for operating MCP servers on Kubernetes.

01

Architecture

AI client
  -> Kavrynt Gateway
  -> registered MCP server

kavryctl / Operator
  -> Kavrynt Registry
  -> Gateway route table
02

MVP lifecycle

define MCPServer
  -> sync to Registry
  -> Gateway loads route
  -> client calls /mcp/<name>
  -> upstream MCP server responds
03

Security baseline

The MVP uses non-root containers, read-only root filesystems, least-privilege RBAC, Helm validation, Docker builds, Go tests, vet, and vulnerability scanning in CI.

04

Repositories

The public alpha should expose source code, docs, issues, releases, checksums, and contribution guidelines.
