DEVELOPER QUICKSTART

Run Kavrynt
on your laptop.

This is the planned public alpha path for testing Kavrynt with Docker, Kind, kubectl, and Helm.

01

Prerequisites

Install these first. Kavrynt uses them to create a local Kubernetes cluster and run the MVP components.

docker version
kind version
kubectl version --client
helm version
02

Install kavryctl

The installer expects published GitHub release assets. Until the first release is published, build from source from the kavryctl repository.

curl -fsSL https://kavrynt.com/install.sh | sh
kavryctl version
03

Run local demo

The target developer workflow is one command to create the cluster, deploy Kavrynt, register a mock MCP server, and verify Gateway routing.

kavryctl demo kind up
kavryctl demo kind status
kavryctl demo kind test
04

Manual test path

For early contributors, the current manual path uses Helm charts and local images from the component repositories.

kind create cluster --name kavrynt-mvp
docker build -t kavrynt/registry:dev ../registry
docker build -t kavrynt/gateway:dev ../gateway
docker build -t kavrynt/k8s-operator:dev ../k8s-operator
kind load docker-image kavrynt/registry:dev --name kavrynt-mvp
kind load docker-image kavrynt/gateway:dev --name kavrynt-mvp
kind load docker-image kavrynt/k8s-operator:dev --name kavrynt-mvp
EXPECTED RESULT

A working MCP route
through Gateway.

curl -fsS http://127.0.0.1:18080/v1/routes
curl -fsS -X POST http://127.0.0.1:18080/mcp/demo-mcp/tools/list \
  -H 'Content-Type: application/json' \
  --data '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

Expected proxy response in the MVP demo: {"method":"POST","mock":true,"path":"/tools/list","route":"demo-mcp"}

PUBLIC ALPHA IMAGES

Container images
for local installs.

docker pull kavrynt/registry:0.1.0-alpha.1
docker pull kavrynt/gateway:0.1.0-alpha.1
docker pull kavrynt/k8s-operator:0.1.0-alpha.1

These tags should be published after the matching source commits are pushed and the repositories are ready for public alpha.

CLEANUP

Remove the local cluster
when finished.

kavryctl demo kind down

# Manual fallback
kind delete cluster --name kavrynt-mvp
