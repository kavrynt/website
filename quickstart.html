QUICKSTART · 0.0.2-BETA.1

Run Kavrynt
on Kubernetes.

Install the signed beta chart on EKS, AKS, GKE, OpenShift, self-managed clusters, or Kind. No source access is needed.

01

Before you begin

You need Kubernetes 1.29+, kubectl, and Helm 3.8+. Docker and Kind are only needed for a local test cluster.

kubectl config current-context
helm version --short

# Local testing only
kind create cluster --name kavrynt-trial
02

Install Kavrynt

One chart installs the MCPServer CRD, the Operator, and the Gateway from signed, multi-architecture images.

helm upgrade --install kavrynt oci://registry-1.docker.io/kavrynt/kavrynt \
  --version 0.0.2-beta.1 \
  --namespace kavrynt-system --create-namespace --wait

kubectl get deployments -n kavrynt-system
03

Declare an MCP server

Point an MCPServer at any MCP server reachable over HTTP in your cluster.

kubectl apply -f - <<'EOF'
apiVersion: kavrynt.io/v1alpha1
kind: MCPServer
metadata:
  name: example-mcp-server
  namespace: default
spec:
  version: 0.1.0
  transport: http
  endpoint: http://example-mcp-server.default.svc.cluster.local:8080
EOF

kubectl get mcpservers
04

Route through the Gateway

Each Ready server is routed at /mcp/<namespace>.<name>. Caller credentials are never forwarded to MCP servers.

kubectl port-forward -n kavrynt-system svc/kavrynt-gateway 18080:8080 &
curl -fsS http://127.0.0.1:18080/v1/routes
