DEVELOPER QUICKSTART

Run Kavrynt
on your laptop.

This is the current public alpha path for testing Kavrynt with Docker, Kind, kubectl, Helm, and the public monorepo.

01

Prerequisites

Install these first. Kavrynt uses them to create a local Kubernetes cluster and run the MVP components.

docker version
kind version
kubectl version --client
helm version
02

Install kavryctl

Until the first tagged release is published, install from the public monorepo. After releases are available, use the website installer.

git clone https://github.com/kavrynt/kavrynt.git
cd kavrynt
go install ./cmd/kavryctl
kavryctl version
03

Install the control plane

Create a local Kind cluster and install Registry, Gateway, and Operator into the kavrynt-system namespace with Helm.

kind create cluster --name kavrynt-dev
helm dependency build charts/kavrynt
helm upgrade --install kavrynt charts/kavrynt \
  --namespace kavrynt-system \
  --create-namespace
kubectl get pods -n kavrynt-system
kubectl get svc -n kavrynt-system
04

Register a sample server

Deploy a temporary HTTP endpoint, then apply the sample MCPServer resource so the Operator syncs it into Registry.

kubectl create deployment example-mcp-server \
  --image=hashicorp/http-echo:1.0 \
  -- -listen=:8080 -text='{"mock":true,"service":"example-mcp-server"}'
kubectl expose deployment example-mcp-server --port=8080 --target-port=8080
kubectl apply -f operator/config/samples/kavrynt_v1alpha1_mcpserver.yaml
kubectl get mcpservers
kubectl describe mcpserver example-mcp-server
05

Release install path

After the first tagged release, developers should be able to install without building from source.

curl -fsSL https://kavrynt.com/install.sh | sh
helm upgrade --install kavrynt oci://ghcr.io/kavrynt/charts/kavrynt \
  --version 0.1.0 \
  --namespace kavrynt-system \
  --create-namespace
EXPECTED RESULT

A working MCP route
through Gateway.

kubectl port-forward -n kavrynt-system svc/kavrynt-registry 18081:8080 >/tmp/kavrynt-registry-pf.log 2>&1 &
registry_pf=$!
kubectl port-forward -n kavrynt-system svc/kavrynt-gateway 18080:8080 >/tmp/kavrynt-gateway-pf.log 2>&1 &
gateway_pf=$!
sleep 3

curl -fsS http://127.0.0.1:18081/v1/servers/example-mcp-server
curl -fsS http://127.0.0.1:18080/v1/routes
curl -fsS http://127.0.0.1:18080/mcp/example-mcp-server

kill "$registry_pf" "$gateway_pf"

Expected proxy response in the MVP demo: {"mock":true,"service":"example-mcp-server"}

PUBLIC ALPHA IMAGES

Container images
for local installs.

docker pull kavrynt/registry:dev
docker pull kavrynt/gateway:dev
docker pull kavrynt/k8s-operator:dev

The dev tags are for early MVP testing. Versioned tags should be used after the first release.

CLEANUP

Remove the local cluster
when finished.

kubectl delete -f operator/config/samples/kavrynt_v1alpha1_mcpserver.yaml
kubectl delete service example-mcp-server
kubectl delete deployment example-mcp-server
helm uninstall kavrynt -n kavrynt-system
kubectl delete namespace kavrynt-system
kind delete cluster --name kavrynt-dev
