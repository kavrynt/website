# Kavrynt GitHub Pages MVP Site

Static GitHub Pages site. No Helm, backend or Node runtime required.

## Pages
- `index.html` — main landing page with animated Map Server deployment pipeline
- `vision.html` — product vision
- `roadmap.html` — MVP → control plane → AI infrastructure
- `docs.html` — architecture and MVP documentation

## MVP visual
Source → Version → Build → Scan + Sign → Verify Policy → Kubernetes → Healthy Runtime

The pipeline animation is pure CSS/JavaScript and loops continuously.

Upload the contents of this directory to the repository used by GitHub Pages. Update the `https://github.com/kavrynt` links when the final repository URLs are ready.
